# Bump to new version

[//]: # @formatter:off

- [Changelog] Update the [changelog](./changelog.md)
- [Version] Bump version name, commit, push
- [GitTag] Tag name: versionName
- [Build] Run `./gradlew file_template_app:clean file_template_app:packageUberJarForCurrentOS`
- [Intellij Ide] Update the path for your External Tool FileTemplateApp in your IDE

[//]: # @formatter:on
